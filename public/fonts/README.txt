FREEDIVE DAHAB - TYPOGRAPHY SYSTEM (LICENSE-SAFE GOOGLE FONTS)
================================================================
The project uses 100% free, open-source Google Fonts:

1. Display Font: Sora (Google Fonts)
   - ExtraBold (800) / Bold (700) / SemiBold (600)
   - Used for: Hero headlines, major section titles, large depth numbers, editorial statements
   - Provides distinctive geometric, architectural, and cinematic character.

2. Body & UI Font: Poppins (Google Fonts)
   - Regular (400) / Medium (500) / SemiBold (600)
   - Used for: Body copy, navigation links, buttons, course cards, labels, metadata, forms
   - Clean, highly readable geometric sans-serif that pairs cleanly with Sora.

Loaded via Google Fonts in index.html with CSS variables in src/index.css:
--font-display: 'Sora', sans-serif;
--font-body: 'Poppins', sans-serif;
